# Edge Function secrets

Supabase reserves environment names starting with `SUPABASE_`. Use these custom names for Edge Functions:

```text
PROJECT_URL
SERVICE_ROLE_KEY
GH_PAT
REPO_OWNER
REPO_NAME
REPO_BRANCH
ADMIN_EMAIL
ADMIN_ORIGIN
```
